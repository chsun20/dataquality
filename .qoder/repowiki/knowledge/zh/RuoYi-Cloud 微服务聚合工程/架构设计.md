根 pom.xml 作为 Maven 聚合父工程（packaging=pom），通过 dependencyManagement 集中声明 Spring Boot 2.6.7、Spring Cloud 2021.0.1、Spring Cloud Alibaba 2021.0.1.0 与 Nacos 客户端等第三方依赖版本，所有子模块继承该 BOM 避免版本漂移；modules 标签按 ruoyi-auth → ruoyi-gateway → ruoyi-modules → ruoyi-api → ruoyi-common → ruoyi-visual 的依赖顺序组织。

运行时分层：
- 入口层：ruoyi_gateway 作为唯一对外 API 网关，承担鉴权、验证码校验、XSS 过滤、限流熔断与路由转发；
- 认证层：ruoyi_auth 独立提供登录/注册/Token 刷新，并通过 Feign 调用 system 模块完成用户校验与日志记录；
- 业务层：ruoyi_modules 聚合系统管理、代码生成、定时任务、文件服务、数据质量五个独立 Spring Boot 应用；
- 横切能力：ruoyi_common 提供 core/security/log/redis/datascope/datasource/swagger 七个通用子模块，被各业务服务共同依赖；
- 远程接口：ruoyi_api 定义 system 服务的 Feign 契约与降级工厂，供其他模块解耦调用；
- 可观测性：ruoyi_visual_monitor 基于 Spring Boot Admin Server 收集各实例健康与指标；
- 前端：ruoyi_ui 通过 Vue2 + Element UI 将后端能力装配为 SPA。

部署与运维由 docker_infra（docker-compose 编排 MySQL/Nacos/Redis/Nginx）与 bin_scripts（Windows 打包/启停脚本）、sql_scripts（建库建表与初始数据）共同支撑，形成从开发到一键部署的闭环。
