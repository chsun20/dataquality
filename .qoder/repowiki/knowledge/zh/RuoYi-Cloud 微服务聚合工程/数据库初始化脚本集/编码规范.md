- 每个脚本以 `DROP TABLE IF EXISTS` 开头清理旧表，再以 `CREATE TABLE ... ENGINE=InnoDB COMMENT=...` 定义结构，并在末尾附带 `commit;`。
- 所有表统一包含 `create_by`、`create_time`、`update_by`、`update_time` 审计字段，并以 `del_flag` / `del` 实现逻辑删除。
- 脚本命名采用 `业务前缀_YYYYMMDD.sql` 格式，通过日期后缀区分不同迭代版本。
- 业务扩展脚本在头部用注释标明适用库（如 `-- 适用：ry-cloud 库`）和日期，便于多环境部署时识别。
