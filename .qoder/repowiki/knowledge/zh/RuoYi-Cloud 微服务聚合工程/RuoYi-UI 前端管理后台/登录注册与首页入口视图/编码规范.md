- 表单页统一使用 Element UI 的 `el-form` + `:rules` 进行声明式校验，并在 `handleXxx` 中通过 `$refs.xxxForm.validate()` 触发验证后再发起请求。
- 验证码能力通过 `getCodeImg()` 接口动态控制：组件维护 `captchaOnOff` 开关与 `codeUrl`/`uuid`，失败时自动刷新验证码图片。
- 登录页将用户名、密码、rememberMe 写入 `js-cookie`，其中密码使用 `jsencrypt.encrypt()` 加密存储，读取时用 `decrypt()` 还原。
- 页面样式采用 `<style lang="scss">` 配合嵌套选择器定义 `.login-form` / `.register-form` 等局部样式块，背景统一引用 `../assets/images/login-background.jpg`。
