本模块由四个独立的 Vue 单文件组件构成，均位于 `src/views/` 下，作为路由层直接面向用户：
- `login.vue`：基于 Element UI 的 `el-form` + `el-input` 构建登录表单，通过 `@/api/login` 获取验证码图片，使用 `js-cookie` 持久化“记住密码”，并通过 Vuex store 的 `Login` action 完成认证，成功后按 `$route.query.redirect` 或 `/` 跳转。
- `register.vue`：复用同一验证码接口，新增 `confirmPassword` 字段与自定义 `equalToPassword` 校验器，提交后调用 `register` API 并弹窗提示成功。
- `index.vue`：纯展示型首页，静态列出项目介绍、技术栈、联系信息与多版本更新日志，仅暴露一个 `goTarget` 方法打开外链。
- `redirect.vue`：极简中转组件，在 `created` 钩子中把 `/redirect/:path` 形式的 URL 替换为 `/` + `params.path`，用于外部链接或第三方回调后的二次路由转发。
依赖方向单向向外：视图 → `@/api/login`（HTTP）、`@/utils/jsencrypt`（前端加密）、`js-cookie`（Cookie 存取）、Vuex（认证状态）；视图之间无相互引用，全部由上层路由表挂载。
