本模块由三个顶层配置文件构成，分别承担不同职责：
- `package.json` 声明项目元信息、npm scripts（`dev`/`build:prod`/`build:stage`/`preview`/`lint`）、husky + lint-staged 的 pre-commit 钩子，以及运行时依赖（vue@2.6、element-ui、axios、echarts 等）与构建期依赖（@vue/cli-service、compression-webpack-plugin、svg-sprite-loader 等）。
- `vue.config.js` 是 Vue CLI 入口，集中配置 publicPath/outputDir/assetsDir、devServer（host 0.0.0.0、端口取自环境变量、按 `VUE_APP_BASE_API` 动态代理到 localhost:8080）、CSS/Sass 输出样式、webpack alias（`@` → src）、CompressionPlugin gzip 压缩、chainWebpack 中移除 preload/prefetch、为 `src/assets/icons` 单独注册 svg-sprite-loader，并在非 development 环境下注入 ScriptExtHtmlWebpackPlugin 内联 runtime chunk、拆分 element-ui/libs/commons 代码块、复制 robots.txt。
- `babel.config.js` 基于 `@vue/cli-plugin-babel/preset`，在 development 环境启用 `dynamic-import-node` 插件以加速热更新。
依赖方向单向：三者均被 @vue/cli-service 消费，彼此之间无相互引用。
