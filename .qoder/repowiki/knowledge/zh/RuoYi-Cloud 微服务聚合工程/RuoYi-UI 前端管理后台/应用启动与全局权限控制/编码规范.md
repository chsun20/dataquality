- 全局能力通过 `Vue.prototype.xxx = fn` 挂载到 Vue 实例原型上，供所有组件直接调用（如 getDicts、parseTime、download 等）。
- 全局组件统一在 `main.js` 中通过 `Vue.component('Name', Component)` 注册，而非按需局部引入。
- 路由级权限校验集中在 `permission.js` 的 `beforeEach` 守卫内完成，按「无 token → 白名单判断」与「有 token → roles 拉取 → addRoutes」两条分支处理。
- UI 行为（Element 尺寸、NProgress 配置）在启动阶段集中初始化，不分散到业务组件中。
