本模块由四个文件构成应用启动链：
- `main.js` 是 webpack 入口，负责挂载 Element UI（尺寸从 `js-cookie` 读取）、注册全局组件（Pagination/RightToolbar/Editor/FileUpload/ImageUpload/ImagePreview/DictTag）、全局方法（getDicts/getConfigKey/parseTime/resetForm/addDateRange/selectDictLabel/selectDictLabels/download/handleTree）以及 directive/plugins/vue-meta，最后实例化 Vue 并引入 `./permission`。
- `App.vue` 仅作为 `<router-view>` 容器，并通过 `vue-meta` 的 `metaInfo` 根据 store 中的 `settings.dynamicTitle` 动态拼接页面标题。
- `permission.js` 在 `main.js` 中通过副作用导入触发，注册 `router.beforeEach` / `router.afterEach` 守卫：未登录时重定向到 `/login?redirect=...`，白名单路径放行；已登录但 roles 为空时调用 `GetInfo` → `GenerateRoutes` → `router.addRoutes` 动态注入可访问路由后重试跳转，同时用 NProgress 包裹导航过程。
- `settings.js` 以 CommonJS `module.exports` 暴露侧边栏主题、tagsView、fixedHeader、sidebarLogo、dynamicTitle、errorLog 等运行时开关，供 store 和布局组件消费。
依赖方向单向：`main.js` → `permission.js` → `store/router/utils/auth`，`App.vue` 仅依赖 store 与 vue-meta，`settings.js` 被其他模块只读引用。
