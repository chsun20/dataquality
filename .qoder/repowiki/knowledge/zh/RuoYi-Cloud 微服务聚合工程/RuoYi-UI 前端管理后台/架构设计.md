以 `src/main.js` 启动应用，由 `app_shell`（入口 + 全局权限守卫）在路由进入前根据后端返回的菜单树调用 `store/modules/permission.js` 生成可访问路由并注入 `router/index.js`；`views_dashboard_auth` 提供登录/注册/首页等无状态页面，其余业务视图按 `system/monitor/tool` 分目录挂载到动态路由下。跨子模块的统一契约包括：
- 所有 API 请求经 `utils/request.js` 封装，统一处理 token、错误码与响应拦截。
- 字典数据通过 `utils/dict/` 下的 Dict 类与 `components/DictTag` 组件在视图层消费，API 侧对应 `api/system/dict/*`。
- 权限指令 `directive/permission/hasPermi.js`、`hasRole.js` 与 `plugins/auth.js` 共同实现按钮级权限控制。
- 布局由 `layout/index.vue` 统一承载 Sidebar、Navbar、TagsView，子模块视图仅负责内容区渲染。
- 构建与开发代理由 `build_config`（vue.config.js、package.json scripts、.env.*）集中管理，前后端联调通过 devServer.proxy 转发至后端服务。
