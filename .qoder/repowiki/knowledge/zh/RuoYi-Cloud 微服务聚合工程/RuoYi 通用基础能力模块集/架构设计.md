顶层 pom.xml 以 packaging=pom 聚合 7 个子模块，依赖方向自下而上：
- ruoyi-common-core：最底层公共库，提供 R/AjaxResult 统一响应体、全局异常体系（exception/* 按 auth/file/user/job/base 分层）、常量（constant/*）、工具类（utils/* 含文件、日期、UUID、JWT、IP、Bean、SQL、反射等）、Web 基类（web/controller/BaseController、web/domain/BaseEntity/TreeEntity、web/page 分页）以及 Spring 自动装配入口 spring.factories。
- ruoyi-common-security：基于 core 构建，通过 WebMvcConfig 注册 HeaderInterceptor 解析 Token，PreAuthorizeAspect/InnerAuthAspect 实现 @RequiresPermissions/@RequiresRoles/@InnerAuth 注解式鉴权，GlobalExceptionHandler 集中处理 core 抛出的各类异常并返回 AjaxResult；同时暴露 FeignRequestInterceptor 供微服务调用。
- ruoyi-common-log / ruoyi-common-datascope：纯 AOP 扩展，分别通过 @Log + LogAspect 和 @DataScope + DataScopeAspect 在 Controller 层切面采集操作日志与数据权限过滤，依赖 core 的 ServletUtils/SecurityUtils 及 security 的 SecurityUtils。
- ruoyi-common-redis：封装 RedisTemplate，提供 FastJson2JsonRedisSerializer 序列化与 RedisService 便捷 API。
- ruoyi-common-swagger：基于 Swagger2 的自动配置 EnableCustomSwagger2 + SwaggerAutoConfiguration/SwaggerWebConfiguration。
- ruoyi-common-datasource：仅声明 Master/Slave 注解，由上层动态数据源切换逻辑消费。
所有可被 Spring Boot 发现的组件均通过各自 META-INF/spring.factories 注册 EnableAutoConfiguration，使各子模块可独立引入。
