模块为 Maven 聚合 POM（ruoyi-visual/pom.xml），仅包含单一子模块 ruoyi-monitor，打包产物 artifactId 为 ruoyi-visual-monitor。

- 入口类 `RuoYiMonitorApplication` 通过 `@EnableAdminServer` + `@SpringBootApplication` 启动 Spring Boot Admin Server。
- 安全层 `config/WebSecurityConfigurer` 继承 `WebSecurityConfigurerAdapter`，基于 `AdminServerProperties.getContextPath()` 动态放行 `/assets/**`、`/login`、`/actuator/**`、`/instances/**`，其余请求需认证；同时启用 formLogin、httpBasic 并关闭 CSRF。
- 配置位于 `bootstrap.yml`：Tomcat 端口 9100，应用名 `ruoyi-monitor`，默认激活 `dev` profile，并通过 Nacos Discovery/Config 连接 `127.0.0.1:8848`，共享配置读取 `application-${profile}.yml`。
- 依赖方向单向：本模块仅依赖 spring-boot-admin-server、spring-cloud-alibaba-nacos、sentinel、spring-security、spring-web，不反向依赖业务模块，作为被注册方（client 端需在各自模块引入 actuator 暴露 `/actuator`）。
