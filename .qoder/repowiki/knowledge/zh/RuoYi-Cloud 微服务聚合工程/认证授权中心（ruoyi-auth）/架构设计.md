模块为独立的 Spring Boot 可执行应用（`RuoYiAuthApplication`），通过 `@EnableRyFeignClients` 启用 Feign 客户端，并显式排除 `DataSourceAutoConfiguration` 表明自身不直连数据库，所有数据访问均经由 `system.api` 远程接口。

内部按职责分层：
- `controller/TokenController`：暴露 `/login`、`/logout`、`/refresh`、`/register` 四个 REST 端点，仅做请求组装与结果包装（统一返回 `R<?>`）。
- `service/SysLoginService`：封装用户名/密码长度校验、状态检查、密码比对、以及通过 `RemoteUserService` / `RemoteLogService` 调用 system 模块进行用户查询、注册与登录日志落库。
- `form/LoginBody`、`form/RegisterBody`：作为入参 DTO。

依赖方向单向指向 `com.ruoyi.common.security`（`TokenService`、`SecurityUtils`、`AuthUtil`、`JwtUtils`）和 `com.ruoyi.system.api`（`RemoteUserService`、`RemoteLogService`、`SysUser`、`LoginUser`），自身不实现安全策略与持久化逻辑。运行期通过 Nacos 完成服务发现与配置拉取（`bootstrap.yml` 中 `spring.cloud.nacos.discovery/config.server-addr=127.0.0.1:8848`），默认监听 9200 端口。
