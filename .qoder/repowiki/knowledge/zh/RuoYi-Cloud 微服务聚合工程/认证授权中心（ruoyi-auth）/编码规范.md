- 对外 API 统一使用 `R<?>` 作为响应体，成功路径走 `R.ok(...)`，失败路径抛出 `ServiceException` 由全局异常处理。
- 跨模块数据访问一律通过 `system.api` 的 `RemoteUserService` / `RemoteLogService` Feign 客户端，并以 `SecurityConstants.INNER` 标识内部调用。
- 用户输入校验集中在 `SysLoginService` 内，依据 `UserConstants.USERNAME_MIN_LENGTH/MAX_LENGTH` 与 `PASSWORD_MIN_LENGTH/MAX_LENGTH` 常量进行长度校验，再抛 `ServiceException`。
- 登录/注册/登出等关键操作通过 `recordLogininfor` 统一写入 `SysLogininfor` 并异步落库到 system 模块的日志服务。
