- 所有全局过滤器实现 `GlobalFilter` 并实现 `Ordered`，通过 `getOrder()` 返回负数（如 -200）控制执行优先级。
- 跨组件通信通过向 `ServerHttpRequest.Builder` 添加/移除 Header 传递用户信息（USER_KEY、DETAILS_USER_ID、DETAILS_USERNAME），而非使用上下文对象。
- 配置项集中放在 `config.properties` 子包下，使用 `@ConfigurationProperties` 绑定 Nacos 下发的 yml 配置（如 IgnoreWhiteProperties、XssProperties、CaptchaProperties）。
- 错误响应统一通过 `ServletUtils.webFluxResponseWriter` 写出，避免直接操作 `ServerHttpResponse`。
