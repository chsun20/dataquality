- 每个远程接口以 `RemoteXxxService.java` 命名并通过 `@FeignClient(contextId = "remoteXxxService", value = ServiceNameConstants.XXX_SERVICE, fallbackFactory = RemoteXxxFallbackFactory.class)` 声明。
- 每个 Feign 接口在 `factory/` 下配套一个同名 `*FallbackFactory`，实现 `FallbackFactory<RemoteXxxService>`，在 `create(Throwable)` 中返回匿名实现并统一用 `R.fail(...)` 包装异常信息。
- 跨服务调用的请求头统一使用 `@RequestHeader(SecurityConstants.FROM_SOURCE) String source` 传递来源标识。
- 所有远程方法返回值统一封装为 `com.ruoyi.common.core.domain.R<T>`，而非直接返回业务对象。
