本模块为纯 API 契约子模块（artifactId: ruoyi-api-system），不引入 Spring Boot 启动依赖，仅暴露给其他服务消费。
- 接口层：`RemoteUserService`、`RemoteFileService`、`RemoteLogService` 三个 `@FeignClient` 接口，分别绑定 `ServiceNameConstants.SYSTEM_SERVICE` / `FILE_SERVICE`，声明 `/user/info`、`/user/register`、`/upload`、`/operlog`、`/logininfor` 等 REST 端点，统一返回 `R<T>` 结果封装。
- 领域模型：`domain/` 下放置与 system 服务共享的实体（SysUser、SysRole、SysDept、SysDictData、SysFile、SysOperLog、SysLogininfor 等）；`model/LoginUser` 为登录态 DTO。
- 容错层：`factory/` 下每个 Feign 接口对应一个 `*FallbackFactory`，实现 `FallbackFactory<T>`，在远端不可用时记录错误并返回 `R.fail(...)` 的本地代理对象。
- 依赖方向：仅依赖 `ruoyi-common-core`（提供 `R`、`SecurityConstants`、`ServiceNameConstants`），反向被业务模块依赖，从而解耦系统服务的具体实现。
- 无运行时装配：未注册 `spring.factories`，由调用方自行启用 `@EnableFeignClients`。
