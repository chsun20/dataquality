- 每个可独立构建的服务目录都包含一个 `dockerfile`，使用 `FROM` 指定基础镜像并通过 `COPY ./jar/*.jar` 引入本地产物。
- 外部配置与数据通过 `docker-compose.yml` 中的 `volumes` 映射到宿主机 `./xxx/conf`、`./xxx/data`、`./xxx/logs` 目录以实现持久化。
- 服务间通信通过 compose 的 `depends_on` 声明启动顺序，并通过 `links` 提供容器名解析。
- 运维脚本采用 shell 函数 + case 分发模式，对外暴露 `port/base/modules/stop/rm` 等语义化子命令。
