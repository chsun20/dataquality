顶层 `pom.xml` 为 Maven 聚合 POM（packaging=pom），通过 `<modules>` 声明并构建以下五个相互独立的 Spring Boot 应用：
- `ruoyi-system`：系统管理核心，包含用户/角色/菜单/部门/字典/配置/日志等 RBAC 相关 Controller/Mapper/Service。
- `ruoyi-gen`：基于 Velocity 模板的代码生成器，将数据库元信息渲染为 Controller/Domain/Mapper/Service/Vue/JS 等脚手架代码。
- `ruoyi-job`：基于 Quartz 的定时任务管理，封装 `AbstractQuartzJob` + `ScheduleUtils` + `CronUtils` 实现任务调度与日志记录。
- `ruoyi-file`：无数据库的文件存储服务，通过策略模式在 Local/FastDFS/Minio 三种后端间切换，启动时排除 DataSourceAutoConfiguration。
- `ruoyi-dqservice`：数据质量规则引擎服务，集成 Drools（kmodule.xml）、Hive Metastore 代理、MySQL 元数据存储，并提供 Apriori 关联规则挖掘与 Spark WordCount 示例。

每个子模块均为可独立部署的 Spring Boot 应用，入口类统一使用 `@EnableCustomConfig` + `@EnableCustomSwagger2` + `@EnableRyFeignClients` 注解接入公共安全与 Swagger 能力；依赖方向由子模块指向父工程 `com.ruoyi:ruoyi` 及 `ruoyi-common` 公共库，子模块之间不互相依赖。
