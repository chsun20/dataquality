脚本按用途分为两类：
- 传统 Maven 工作流：`package.bat`、`clean.bat` 通过 `cd .. && call mvn ...` 在仓库根目录执行打包/清理。
- 单体 Jar 运行：`run-gateway.bat`、`run-auth.bat`、`run-modules-system.bat`、`run-modules-file.bat`、`run-modules-gen.bat`、`run-modules-job.bat`、`run-monitor.bat` 各自 `cd ../ruoyi-*/target` 后以固定 JVM 参数直接 `java -jar` 启动对应子模块。
- 进程化编排：`start-backend.ps1` 是核心入口，用 PowerShell 对象字典集中声明各服务的 Jar 路径与端口（auth:9200, system:9201, dqservice:9205, gateway:8089），支持 `-Only` 白名单与 `-Stop` 停止模式；通过 `Get-NetTCPConnection` 探测端口、`Start-Process -WindowStyle Hidden` 后台拉起并输出到 `logs\*.out.log` / `*.err.log`，最后轮询等待端口就绪（最长 120s）。
- 前端开发：`start-ui.ps1` 校验 `dataquality-ui-main/node_modules` 存在，设置 `NODE_OPTIONS=--openssl-legacy-provider` 兼容 Vue CLI 4.x，并在独立 PowerShell 窗口中 `npm run dev`。
依赖方向单向：脚本仅消费已构建产物（`ruoyi-*/target/*.jar`、`node_modules`），不反向依赖业务代码。
